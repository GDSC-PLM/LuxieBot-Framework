### Linux/macOS

#### Create virtual environment (venv)

```bash
python -m venv .venv
```

#### Activate the venv

```bash
source .venv
```

### Windows

```bash
python -m venv .venv
```

#### Activate the venv (CMD)

```bash
.venv\Scripts\activate.bat
```

#### Install dependencies

```bash
pip install -r requirements.txt
```
